# 最近实验复核与下一步建议（2026-10-10）

状态：只读日志/源码/探针产物审计；只更新文档。未改模型、未训练、未使用 GPU。
不是新 run 的正式预登记；所有新阈值需在实现和训练前固定。

## 1. 决策

停止 DC-RSSM 家族 AP 扩展与 ep16→24 续训。保留证据场、ego-warp 的机制资产，
但不再直接叠层。回到 `no2d_igdr` 标准 RSSM 为新候选的性能与结构基线。
下一步先核对真实目标与职责，再对“重建目标改革”做一次有明确停止条件的
最小验证；不是立即切换整套对象架构。目标改革未传递到 z/检测决策时转 A；
确认弱/缺测类别负迁移时再单独试 C。B/D 仍后置。

## 3. 必须纠正的证据口径

### 3.1 95.5% 不是现役 DC 真正优化的重建目标

`tools/probe_recon_target.py:68–86` 的 `pool16_globalstd` 是探针候选构造。
低维历史路线 `_normalized_recon_target` 使用 pool + 标准化，但当前 MCI/DC
继承 full-resolution decoder：`mci_rssm.py:768` 用 `[h_t,z_t]` 解码，
`R4Det.py:919–930` 直接算 `MSE(rssm_recon, bev_feats_cache)`；没有 pool16，
没有全局标准化，也没有在这一行 detach 原始目标。
训练 `R4Det.py:1493–1504` 把它登记为 `loss_rssm_recon`。

因此，95.5/4.5% 是“在 DC checkpoint 特征上构造的 pool16 标准化候选”结果，
不是已证实的 DC 训练目标能量分解。该探针尚未测 fullres 原始目标。
同分辨率比较应是 `fullres_globalstd` 特异 15.5699% vs `diff_globalstd`
97.7587%（6.28 倍），而且两者仍经过标准化，不能冒充 raw 训练目标。

### 3.2 §69 中“MAI baseline”实际是标准 RSSM

区域探针 JSON 的 config/checkpoint 和落盘 config 指向
`fgfull_N4_no2d_igdr_2x4_24e_seed0`，类型 `MotionAlignedRSSMFusion`；
不是 `MotionAlignedInnovationRSSMFusion` 的 MAI。因此现有对照支持标准
RSSM 有更强前景集中，不能声称本次已直接测 MAI 的区域集中。

### 3.3 区域 shuffle 不足以定位“只坏在读出头”

DC 前景不比能量匹配背景更敏感，是不支持“简单裁状态即可改善”的证据；
不能唯一排除编码内容、后验、训练监督、读出或探针覆盖问题。
12 个样本的区域表只有 Car/Cyclist，没有 Ped/Truck，不能外推全类别。
只读 shuffle 测到变化，不是标注任务错误，不能等同“换掉就毁掉物体”。
“前景-only 不立项”是按当前预登记的项目决策，不是全体对象方法永久证伪。

### 3.4 样本特异能量不是语义或 z 排他信息

差分也包含自车运动、深度变化、背景边缘、遮挡、噪声、增强差异和特征漂移。
差分目标特异 97.8% 不证明对象语义更多，更不证明 h 不能预测；decoder
仍读 `[h,z]`，仅换目标可能由 h 承担。要测条件增益及真实分类/检测差。
解析对齐降低残差不意味着剩余全是物体运动；当前帧 ego 速度与名义 dt
不是位姿 GT。先不引入 L1 到新实验中，避免另一条失败家族依赖。

### 3.5 旧数字的局部修正

- §68.9h 的 DC1 39.2169 实际高于 MCI-v2−0.5 线 38.8786，差 +0.3383；
  不是该门 FAIL。基线门 −0.0640 与 Ped 门 FAIL 足以保持总终判 FAIL。
- §68.9j 归因中的 MCI-v2 Ped −4.34 不正确；固定 ep12–16 差 −7.8295。
- “家族每次 Ped/Cyc 都大跌”过强：v2 Cyc 同窗为 +0.0652，接近持平。
  类别负迁移明显，但不能把所有运行都描述成同号同幅。
- 文档 2026-10-08 候选标题为 B §3、C §4，用户摘要的 B/C 节号反了；
  机制含义没有歧义，不影响排序。

## 4. 下一步：一个有条件的小实验，不是再堆模块

### 阶段 0：先形成真实目标契约和正式预登记

1. 钉住训练实际目标、decoder 输入、reconstruction loss 梯度（当前 raw target
   有梯度；改成 stop-gradient 也是一个变量）、历史帧监督策略与状态重置。
2. 在分散序列、四类足量 GT 的训练/独立诊断样本中复测 raw fullres current
   vs raw fullres difference，标准化只作为单独对照；报告噪声与能量尺度。
3. 定义 `T_delta = F_t - F_prev` 的帧顺序、有效历史 mask、padding/scene reset、
   同一几何增强、低能量差分与归一化分母规则；无历史不得强迫拟合全零差分。
4. 预登记唯一变量、作用层、数据窗、基线、各类保护门、机制门、ep6/ep16
   检查点和停止条件。所有标定用训练集，禁止根据 val 调阈值。

### 阶段 1：只检验目标内容

选择 **no2d_igdr 标准 full-resolution RSSM**；架构、posterior、KL、readout、
日程不变，不携带 DC 证据场/L1。current vs difference 在相同网格、同一
detach 规则、同一尺度约定下配对，避免同时“差分+detach+标准化+z-only”。
若需新增归一化或切断目标梯度，先建立匹配的 current-target 控制。

推荐最小处理为原始 full-resolution 帧差分，其原始目标梯度契约保持一致；
raw 能量极低时先定义共同训练标定尺度及匹配 control，不事后放大系数。
保留 decoder `[h,z]` 与基线职责是本阶段为了单变量归因，不是认为 h 旁路无害。

450 iter 只查 loss 接线、梯度、目标正确性、decoder 学习、基路行为与资源。
短冒烟不能作 AP 最终裁决，单样本跨类 shuffle 或方差增长不作为成功。
通过后 seed0 ep6 检查，再按预登记决定是否到 ep16；无需立即三 seed/24e。

### 阶段 2：按机制分叉，不做无休止 target 扫描

- 目标学会、z-only 语义仍差、h-only 重建几乎一样：h 旁路/监督职责嫌疑上升；
  转 A，或单独验证 z-exclusive residual reconstruction，不与读出同时改。
- z 有对象语义、真实分类/检测无贡献：优先 A 的检测 residual 读出。
- 分类改善但 Ped/Cyc 3D AP 不涨：拆 recall、中心/尺寸/朝向、NMS/score，
  不继续把问题统称分类；弱/缺测组才触发 C。
- 目标/噪声或几何验证不过：差分候选停止，不进入长训。
- seed0 小实验没有任务级收益或破坏基线对象集中：记录负结果、转 A；
  不以“再调 KL、扩大增益、续 ep24”救活。

### 接受条件边界

新 run 的数值门尚未批准：建议固定 ep12–16 配对 Overall 有正收益，Car/Truck
strict、Ped/Cyc loose 均不低于预先约定的非劣界，且 z 对真实任务有增量。
机制探针用足量独立 clip 和逐类样本，不把 12 点/2% 输出阈值充当论文有效性。
单 seed 通过才三 seed 配对，最终四类提升需各自报告均值、波动和峰值 epoch。

## 5. 论文贡献边界

帧差分重建是基础修复/假设验证，不自动达到论文主贡献。正式贡献可以是
“检测接地的创新状态学习+验证其对象语义与条件任务价值”，配合 A/C 中
经独立消融确认的部分。对象中心和 latent overshooting 已有 prior art，
不因换名字就新颖。本次不新增论文首创断言、不部署候选。

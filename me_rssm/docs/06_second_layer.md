# 06 · 第二层结构审查（实现 ME-RSSM 之后的再审视）

> 审查对象：加入 ME-RSSM 后的完整网络。方法：沿 01 的信息流逐环节重走一遍，
> 问"现在最弱的一环是什么"。结论按优先级排列，作为后续研究循环的输入。
> 全部结论仍为静态分析，不含任何训练/验证信号。

## 1. 新网络还存在的结构问题（按优先级）

### P1 · 状态初始化仍为死状态（02 #7 未解，维持原判）

> **2026-09-19 更新：已实现（`state_init='obs'`，零初始化 1×1 conv 从首帧
> 观测 bootstrap h_0/z_0 + reset_for_samples pending 语义），sanity 13/13
> 全绿，详见 docs/07。未训练——严格排在主线 seed0 判定之后。**

h_0=z_0=0（rssm_fusion.py:666-670）。N=4 时第一历史帧的转移从零状态出发，
其 deform align 作用于零张量、GRU 候选仅由 z_a=0 驱动——第一帧观测基本只通过
当帧 posterior 进入。改进方向（已在基线接口内可实现的两种）：
- **先验引导初始化**：reset 后第一次 forward 时 h_1 = GRU(e_1, 0)（把首观测
  编码直接灌入转移），或
- **可学习初始状态**（小卷积从 e_1 生成 h_0）。
代价 <0.1M，风险低；但独立贡献小，建议与其它机制组合验证。**下一循环首选。**

### P2 · gain 缺少 innovation 输入（C2 的已知简化）

当前 g = σ(conv([c_cam, c_mot])) 只看"观测可靠性"，不看"观测与预测的分歧度"。
Kalman 框架里 gain 同时依赖测量噪声与先验协方差——innovation（μ_q−μ_p）的
逐像素幅值是现成的免费信号。扩展：`g = σ(conv([c_cam, c_mot, |μ_q−μ_p|⊗]))`。
需要谨慎的点：innovation 大可能是"目标真的动了"（该信观测）也可能是
"观测是杂波"（该信预测）——语义双向，静态分析无法定论，故**不预实现**，
等 full 模型的 stat_gain / stat_conf 分布出来后再决定（保留为预注册候选）。

### P3 · align_h / align_z 双对齐器冗余（02 #14a，维持）

两套 deform aligner（~1.2M 参数）处理高度相关的状态。合并方案：h/z concat
后单对齐，或仅对齐 h、z 沿用同一位流场。属"动已验证机制"，收益（省参数）
与风险（破坏已验证的 align_z_state 行为）不对称，**维持冻结**，仅记录。

### P4 · 检测头不确定性缺失（02 #12，维持推迟）

g、σ_q、innovation 都已就绪可下游化（如 1 通道 confidence 图拼接进 head stem），
但 head 侧改动在项目历史中六连败（零和）。等 ME-RSSM 机制本身经训练检验后
再评估。**维持推迟。**

### P5 · 重建目标未区分动静（02 #5 关联）

recon 仍重建融合外观 BEV（被验证机制，冻结）。二线候选：对动态证据 d 高的
区域加权 recon（把重建容量引向"会变的东西"）——与 P1 同属"等首轮训练信号
再动"的增量。

## 2. 本轮实现新引入的契约与风险（诚实清单）

| 契约/风险 | 说明 | 缓解 |
|---|---|---|
| 边带通道生命周期 | bus 每帧写、当帧读；`_read_context` 三重形状守卫，不一致即降级基线 | 已实测守卫生效（05 §2-1）；守卫降级时 DDP 下会因参数未被使用而报错——**训练配置必须使用完整 producer 链**（新 PFN+scatter+stash fusion 三件套），降级路径仅供 eval/sanity |
| 冷启动链 | encoder/conf 分支第 1 步梯度为 0（零初始化残差下游） | G1a/G1b 验证第 2 步激活；如需一步激活可调 obs_proj 微随机初始化（默认不启用） |
| modality_dropout 的双重身份 | 既是鲁棒性机制也是 fallback 通路的训练压力来源 | 默认 0（行为=基线平滑延拓）；开启与否列为预注册消融 |
| β 有界性 | tanh(β) 保证 update gate 恒为合法概率 | 数学保证（04 §2），无训练自律依赖 |
| 稀疏证据的池化稀释 | avg_pool(2) 把单热点稀释 4× | count 通道（ch6）可供补偿；如训练显示速度证据过弱，备选方案是 count-weighted scatter 或 max-pool（预注册，不预先实施） |
